给我创建一个番茄钟，技术是python，虚拟环境已建好，要求打包后能运行在windows 和 macOS 的后台，在系统图标栏上显示图标。
 
 * python 需要的库在虚拟环境里自行安装，维护好 requirements.txt
 * 有一个设置界面，能设置一个番茄钟的时长，短休息时间，以及多少次之后进行长休息，长休息是多少时间
 * 每次完整经历一个番茄钟可以获得一个番茄，番茄数据每日清空，但是会记录总数
 * 主界面是番茄树界面，用 imgs/bg.png 填满。左下角显示总番茄数。
 * 番茄图片用 imgs/tomatos16.png，这是一个 4*4 共16个番茄的小图，可选的坐标位置在  configs/tomato_positions.json
 * 每获得一个番茄，当日番茄加一，番茄总数加一，当日缓存文件记录番茄的位置和图片标号
 * 每次获得番茄进入休息时间，会自动弹出番茄树界面，然后等一秒增加一个番茄，总数加1
 * 遇到有全局设置参数可以放在  configs/app_config.json
 * mac 和 windows 不同的部分，用接口类实现
 * 做到代码分工合理，职责明确，可阅读性强
